# Presentaciones — Club de Monetización

Catálogo de diapositivas de las clases. Sitio estático: `index.html` (todas las clases
dentro, la navegación va por `#clase-N`) y `logo.png`. Vercel lo publica tal cual,
sin build. Dominio: presentaciones.clubdemonetizacion.com

El timer de la pausa entre partes de la clase vive aparte, en `timer/index.html`
(se abre en `/timer`, y el portal lo enlaza arriba del buscador).

Para agregar una clase: añadirla al arreglo `CLASSES` de `index.html`, subir y listo.

Se despliega solo: cada push a `main` publica el sitio en Vercel.
